# Africa Shield Cyber Centre

Threat-intelligence and reporting desk for African security operations.

The site is a multi-page operations console: public reporting, a SOC view, a live-style threat map, careers, and an admin authentication path.

## What is in this repository

| Area | Purpose |
| --- | --- |
| `Home` | Centre landing and mission |
| `Report` | Incident and feedback submission |
| `SOC` | Security-operations view |
| `ThreatMap` | Geographic threat picture |
| `Learn` | Awareness and education pages |
| `Events` / `Career` / `Contact` | Centre operations |
| `Admin` | Authentication and registration |
| `api` | PHP endpoints for auth and reports |

## Stack

HTML · CSS · JavaScript · PHP
